# Header images

Finalized Memory Survival headers, generated from the production S2 identity
and an authentic iPhone gameplay capture.

| File | Dimensions | Intended use |
| --- | ---: | --- |
| `apple-store-feature-5244x2950.png` | 5244 × 2950 | Apple Store promotional header |
| `apple-store-feature-3840x1646.png` | 3840 × 1646 | Apple Store wide promotional header |
| `website-hero.png` | 2400 × 1200 | Website hero and large campaign placements |
| `x-header.png` | 1500 × 500 | X profile header |
| `facebook-cover.png` | 1640 × 624 | Facebook Page cover |
| `linkedin-cover.png` | 1128 × 191 | LinkedIn company cover |
| `youtube-channel-banner.png` | 2560 × 1440 | YouTube channel art; essential content is inside the central 1546 × 423 area |
| `press-header.png` | 2400 × 800 | Press kit and editorial masthead |
| `email-header.png` | 1200 × 400 | Newsletter and announcement email header |

All files are opaque sRGB PNGs. Platform interfaces may crop headers
differently by device, so preview each asset in the destination interface
before publishing.

Rebuild from the repository root:

```sh
python3 marketing/tools/build_campaign_assets.py
```
