# Memory Survival — Logo Exploration, Round 2

These are exploratory renderings, not approved production assets. (Round 4 later selected S2; see ../logo-round-4-survival/SELECTED.md.) The current
identity files under `marketing/assets/identity/` remain unchanged until a
direction is selected and rebuilt as a controlled vector master.

## A — Contiguous Core

`a-contiguous-core.png`

A protected mint process surrounded by an almost-complete contiguous ring. It
communicates defense and allocation clearly, but the circular construction may
feel more like a strategy or security game than a one-dimensional puzzle.

## B — The Last Gap

`b-last-gap.png`

Opposing blocks separated by a dangerous fault line. This has the strongest
thumbnail silhouette and most immediate sense of jeopardy. It is the least
literal and the best candidate for a distinctive consumer-game identity.

## C — Compact / Release

`c-compact-release.png`

Blocks converge on a mint center while one coral process disintegrates. It
captures compaction and release, although the radial composition is less true
to the game's one-dimensional memory strip.

## D — Heapline

`d-heapline.png`

A precarious vertical contiguous run interrupted by a coral block. This is the
closest match to the actual board and has strong tension, but it needs a flatter
vector treatment to avoid reading as a generic stack or tower game.

## Recommendation

Advance **B — The Last Gap** and **D — Heapline** into a third round of flatter,
more ownable vector-style refinements. Test both at 32 px before selecting the
final icon. B is the stronger brand mark; D is the stronger expression of the
actual mechanic.
