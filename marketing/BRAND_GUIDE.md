# Memory Survival — Brand Guide

**Status:** Pre-release identity — S2 “Shrinking Safe Corridor” selected 2026-10-05  
**Prepared:** October 5, 2026  
**Publisher:** Nelson Grey LLC

## Positioning

Memory Survival is a real-time mobile puzzle about fitting processes into contiguous memory while lifetimes, deadlines, and allocation storms reshape the board.

The brand should feel precise, tense, and readable—not like a memory-training app, a coding tutorial, or a generic cyberpunk game.

## Naming recommendation

Use **Memory Survival** as the working product title. Always pair it with the category clarifier **“A real-time memory allocation puzzle”** on first exposure.

Preliminary search found older uses of the exact phrase for a memory-pairs Android game and a commercial minigame. This is not a clearance opinion. Before store registration or a public announcement, complete trademark, store, domain, and common-law clearance. If a more ownable primary title is needed, the strongest working alternative is **Heapline: Memory Survival**.

## Messaging hierarchy

- Primary headline: **Every gap is a risk.**
- Short action line: **Place. Release. Compact. Survive.**
- Category line: **A real-time memory allocation puzzle.**
- Long description: **Place incoming processes, read their lifetimes, and protect enough contiguous space to survive escalating allocation storms.**
- Pre-release status: **In development for mobile. Screens, balance, features, and release plans may change.**

## Visual system

- Graphite `#10151C`: primary background
- Panel `#1B2430`: raised surfaces
- Near white `#EEF2F6`: primary type
- Muted steel `#A9B4C2`: supporting type
- Allocation blue `#2F6AA0`: active processes
- Survival mint `#6FD9B0`: healthy state and calls to action
- Fault coral `#FF8A75`: danger only

Use Sora Bold for display copy and Sora Regular/Semibold for supporting copy. Keep layouts spacious and geometric. Never rely on color alone to communicate state.

## The mark

**S2 — Shrinking Safe Corridor.** Three contiguous cells (mint on top, two allocation-blue below) hold a narrow corridor open while two fault-coral walls close in from either side. It says *contiguous allocation* and *survival under pressure* in one picture: the corridor is being compressed, and it is still holding.

- The walls lean toward the middle cell and stop 22 px (of 1024) short of the stack. Do not widen that gap; the squeeze is the idea.
- The walls cover roughly 44% of the tile, about a fifth less than the original concept, so the cells carry the icon.
- Depth is limited to a light top edge and a darker lower edge on each shape. No gloss, glow, texture or particles.
- No text, hearts, shields, flames, RAM sticks, circuit boards, batteries or traffic lights.
- Sources: `assets/source/s2-mark.svg` (rounded tile) and `s2-app-icon.svg` (full-bleed square). Verified legible at 16, 32, 64 and 128 px (`assets/identity/s2-contact-sheet.png`).

## Wordmark

Set in **Sora Bold**, two lines, tracked −2%: **MEMORY** in near white `#EEF2F6`, **SURVIVAL** in survival mint `#6FD9B0`. Horizontal (`s2-wordmark-horizontal.svg`), stacked (`s2-wordmark-stacked.svg`) and type-only (`s2-wordtype-stacked.svg`) versions exist. The mark and the wordmark each work alone.

## Logo rules

- Use the horizontal wordmark on website heroes, press material and wide social assets; the stacked one where height is available.
- Use the mark alone for avatars, favicons and store icons. The app icon is full-bleed and square; let the platform round it.
- On dark pages the tile carries a hairline steel edge so it does not dissolve into the page. Keep it.
- Minimum clear space: one cell width (a quarter of the tile width) on every side. Minimum size: 16 px for the mark, 120 px wide for the wordmark.
- Do not rotate, recolour, add gradients or outlines, or stretch. Do not place directly over busy artwork without a dark field.
- Coral is a danger colour; outside the mark use it only for faults.

## Imagery rules

Campaign artwork should show ordered cells, contiguous blocks, empty gaps, and one controlled fault state. Avoid binary rain, motherboard photography, server racks, humanoid AI imagery, and neon cyberpunk clutter.

The logo, wordmark and social layouts are original vector work. The earlier campaign key art (`assets/campaign/key-art-master.png`) was generated with OpenAI's built-in image-generation tool; it is no longer used in social exports but still appears on the website hero. Treat it as AI-generated and retain that provenance. The S2 concept reference image is also AI-generated and was only a visual guide.

## Accuracy boundary

Until release evidence exists, do not say “available now,” “download,” “players,” “hit game,” or quote retention/performance claims. Daily mode, authored scenarios, leaderboards, platform availability, and other functionality must be rechecked against the release candidate before store copy is finalized.
